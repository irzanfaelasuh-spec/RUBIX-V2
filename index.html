CUBE X GUIDE

Know your notation.

Each letter names a face. Add an apostrophe for a counterclockwise turn, or 2 for a half turn.

R / LRight / Left
U / DUp / Down
F / BFront / Back
R′Counterclockwise
U2180° half turn
2RSecond layer (larger cubes)

The solver uses the recorded legal move sequence to return the current session to solved state. It does not solve arbitrary hand-entered cube states.
